# Report schema (v1.0)

Every analysis writes `<analysis_id>_report.json` and `<analysis_id>_summary.csv`; videos also write
`<analysis_id>_tracks.csv` (one row per track = per-fruit export) and, if `video.store_detections: true`,
`<analysis_id>_detections.csv`. A **synthetic** example generated by the real report builder is in
[`sample_report.json`](sample_report.json) (values are illustrative, not measurements).

| JSON path | Meaning | Unit |
|---|---|---|
| `schema_version`, `analysis_id`, `input_filename`, `analysis_timestamp_utc`, `mode` | identity (filename only, never a local path) | - |
| `demo_mode` | `true` if a generic model was used; results must not be used for decisions | bool |
| `model.*` | checkpoint name, size, SHA-256 prefix, Ultralytics version, device, class names | - |
| `inference_config.*` | imgsz, thresholds, tracker, camera mode, frame stride, maturity settings | - |
| `video.*` | width, height, fps, `fps_source` (`metadata`/`fallback`), frame counts, throughput, `terminated_early` | px, fps |
| `counts.raw_frame_detections` | every detector box in every processed frame (images: before filtering). **Not a fruit count for video** | boxes |
| `counts.rejected_detections` | failed geometry/confidence validation or near-identical duplicates | boxes |
| `counts.confirmed_tracks` | video: tracks seen in >= `min_confirm_observations` processed frames (`null` for images) | tracks |
| `counts.estimated_unique_visible_fruit` | policy-based estimate of distinct *visible* fruit (includes manual additions) | fruit |
| `counts.by_species / by_maturity / by_condition / by_zone` | breakdowns; `unavailable` = no model ran, `uncertain` = below confidence threshold | fruit |
| `counts.manual_additions / manual_rejections` | manual review, kept separate from model output | fruit |
| `counts.estimate_basis` | text describing how the estimate was derived and its caveats | - |
| `counts.track_diagnostics` | track fragmentation indicators (video) | - |
| `harvest.visible_harvestable_count` | unique visible * harvestable probability (**unrounded**); `null` if probability not configured | fruit |
| `harvest.visible_harvest_weight_kg` | harvestable count * avg weight (g) / 1000 | kg |
| `harvest.estimated_total_tree_fruit`, `tree_harvestable_count`, `tree_harvest_weight_kg` | extrapolated via `visibility_fraction`; `null` unless configured | fruit / kg |
| `assumptions.*` | average weight, harvestable probability, visibility fraction actually used | g, 0-1, (0-1] |
| `uncertainty` | empirical prediction interval from field-validation pairs, else `null` | kg |
| `uncertainty_note` | why there is / isn't an interval | - |
| `warnings`, `limitations`, `definitions` | human-readable caveats and metric definitions | - |

Summary CSV column order is fixed (`src/reporting.py::SUMMARY_COLUMNS`); dictionary-valued fields are
stored as JSON strings in columns ending `_json`.
